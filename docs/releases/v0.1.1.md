# Waras Arta v0.1.1 — Alpha 2

Pembaruan berdasarkan masukan tester: input nominal lebih mudah dibaca, pilihan ikon lebih lengkap, pengelolaan anggaran lebih nyaman, dan pembaruan aplikasi kini tersedia dari halaman Tentang.

## Yang baru

- **Format nominal otomatis:** pemisah ribuan tampil saat mengetik, misalnya `1500000` menjadi `1.500.000`.
- **Tambahan ikon kategori:** listrik, air, bahan bakar, laptop, perangkat, serta berbagai sumber pendapatan.
- **Ikon anggaran pilihan sendiri:** dapat dipilih pada form tambah/edit, termasuk untuk anggaran multi-subkategori. Mode Otomatis tetap tersedia.
- **Pemilih subkategori anggaran lebih ringkas:** pencarian kategori/subkategori, ikon, centang grup, dan jumlah pilihan tanpa kartu besar serta tombol berulang.
- **Pembaruan dari dalam aplikasi:** buka **Tentang → Pembaruan aplikasi** untuk memeriksa rilis, membaca catatan perubahan, mengunduh APK dengan progres/pembatalan, dan membuka pemasang Android. Pemasangan tetap memerlukan konfirmasi pengguna.

## Cara memperbarui dari v0.1.0

1. Buat backup `.warasarta` terbaru dan simpan kata sandinya dengan aman.
2. Unduh asset **`waras-arta-v0.1.1-android.apk`** pada rilis ini, bukan arsip source code.
3. Buka APK, izinkan pemasangan dari sumber tersebut jika diminta, lalu pilih pembaruan pada Android.
4. **Pasang di atas aplikasi lama. Jangan uninstall atau hapus data.** Jika Android menolak karena signature berbeda, jangan menghapus aplikasi; laporkan terlebih dahulu.
5. Setelah selesai, buka Tentang dan pastikan tampil **Versi 0.1.1 (2)**. Periksa kembali transaksi, rekening, kategori, anggaran, dan buat backup baru.

APK publik v0.1.0 belum memiliki fitur pembaruan internal, sehingga perpindahan ke v0.1.1 masih dilakukan secara manual. Setelah memakai v0.1.1, rilis berikutnya dapat diperiksa dan diunduh dari dalam aplikasi.

## Data dan backup

- Data lama dimigrasikan tanpa perlu reset; ikon anggaran lama memakai mode otomatis.
- Backup mencakup kategori, ikon pilihan, transaksi, rekening, dan anggaran.
- Backup baru menggunakan **payload v5/schema database v7**. Format terenkripsi `.warasarta` dan kata sandi tetap digunakan.
- Backup lama v1–v4 tetap dapat dipulihkan. **Backup dari v0.1.1 tidak dapat dipulihkan pada v0.1.0.** Untuk perangkat pengganti, pasang v0.1.1 atau versi lebih baru yang mendukung format backup tersebut.
- Kata sandi backup tidak disimpan dan tidak dapat dipulihkan jika terlupa. Database aktif tetap berada di penyimpanan privat aplikasi, tetapi belum dienkripsi secara khusus oleh Waras Arta.

## Koneksi dan izin

Pencatatan keuangan tetap dapat digunakan offline. GitHub hanya dihubungi saat pengguna meminta cek/unduh pembaruan; catatan keuangan dan file backup tidak dikirim. Izin pemasangan digunakan untuk membuka pemasang pembaruan Waras Arta, bukan memasang aplikasi diam-diam. Penjelasan privasi di dalam aplikasi telah diperbarui.

## Batasan versi alpha

- Masih merupakan versi pengujian dan mungkin memiliki bug. Simpan beberapa salinan backup; jangan menjadikannya satu-satunya catatan keuangan penting.
- Pengunduh belum mendukung resume setelah proses aplikasi dihentikan OS; unduh ulang dimulai dari awal.
- Membuka pemasang belum berarti pembaruan berhasil. Konfirmasikan dan selesaikan proses pemasangan Android.
- Alur pemasangan pembaruan menyeluruh melalui aplikasi masih memerlukan smoke test dengan rilis lebih baru. Pemeriksaan versi sudah dicoba pada perangkat; logika unduh/verifikasi/izin/pemasang juga diuji secara otomatis menggunakan fixture dan installer palsu.
- Tujuan Keuangan, utang/piutang, backup otomatis, dan sinkronisasi cloud belum tersedia.
